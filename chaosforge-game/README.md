# ChaosForge Game

A simple game written in C.

## Building

To build the game, run the `make` command in the `chaosforge-game` directory:

```sh
make
```

This will compile the source code and create an executable file named `chaosforge`.

## Running

To run the game, execute the `chaosforge` file:

```sh
./chaosforge
```

## Source Files

*   `main.c`: The main entry point of the game.
*   `game_state.c`/`.h`: Manages the game's state.
*   `player_controller.c`/`.h`: Handles player input and movement.
*   `combat_system.c`/`.h`: Manages the combat mechanics.
*   `physics_manager.c`/`.h`: Handles the physics simulation.
